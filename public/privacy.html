SEED 개인정보 처리방침

최종 수정일: 2026년 9월 17일 · 적용 대상: SEED 안드로이드 앱 및 웹 게임(kukuma1004.github.io/seed-web)

요약 — SEED는 회원가입, 이메일, 전화번호, 주소, 사진, 정확한 위치를 요구하지 않습니다. 명예의 전당을 위해 플레이어가 직접 적은 별명, 익명 사용자 ID와 게임 기록이 서버에 저장됩니다. 광고와 결제는 없습니다.

1. 수집하는 정보

항목수집 시점목적보관 위치
별명(최대 8자), 점수, 진행한 여정·방 번호, 처치 수, 플레이 시간게임이 끝나 랭킹에 기록될 때모두의 랭킹(명예의 전당) 표시Google Firebase Realtime Database(싱가포르)
익명 식별자(무작위 문자열)랭킹에 처음 연결할 때 자동 생성같은 기기의 기록을 하나로 묶고, 본인 기록만 수정·삭제할 수 있게 함Google Firebase Authentication(익명 로그인)
접속 IP, 기기·브라우저 종류를 나타내는 사용자 에이전트익명 로그인과 랭킹 서버 연결 시서비스 보안, 부정 이용 방지, 연결 제공. IP로 대략적인 지역이 추정될 수 있으나 SEED 운영자가 위치 정보를 따로 저장하거나 이용하지 않음Google Firebase
게임 진행 상황, 설정, 도감, 이 기기 기록플레이 중이어하기와 화질 설정기기 안(브라우저 저장소). 서버로 보내지 않음

익명 식별자는 구글 계정이나 실제 신원과 연결되지 않습니다. 앱을 지우거나 브라우저 저장소를 비우면 새 식별자가 만들어집니다.

2. 수집하지 않는 정보

법적 이름·생년월일·이메일·전화번호·주소·연락처·사진·마이크·카메라·정확한 위치·하드웨어 식별자(광고 ID 포함)를 요구하거나 수집하지 않습니다. 앱은 카메라, 마이크, 위치, 연락처, 저장소 권한을 요구하지 않습니다.

3. 광고와 결제

현재 버전에는 광고와 앱 내 결제가 없습니다. 추후 추가될 경우 이 문서를 먼저 고치고, 앱 안에서도 안내합니다.

4. 청소년 이용

SEED는 만 13세 이상 청소년과 성인을 대상으로 합니다. 별명에는 실명, 학교, 학년·반, 전화번호처럼 자신을 알아볼 수 있는 정보를 적지 않도록 게임 안에서 안내합니다. 부적절한 랭킹 별명은 앱 안에서 신고하거나 사용자 단위로 숨길 수 있습니다. 보호자께서 자녀의 기록 삭제를 원하시면 아래 연락처로 별명과 대략적인 기록 시각을 알려 주세요. 확인 후 삭제합니다.

5. 보관 기간과 파기

랭킹 기록은 명예의 전당에 표시하기 위해 보관하며, 시즌 정리나 삭제 요청 시 지웁니다. 기기 안의 저장 내용은 앱 삭제 또는 브라우저 저장소 삭제로 즉시 사라집니다.

6. 제3자 제공과 처리 위탁

수집한 내용을 판매하거나 광고 목적으로 제공하지 않습니다. 다만 서비스 운영을 위해 아래 회사의 기능을 사용합니다.

  • Google Firebase(Google LLC) — 익명 로그인과 랭킹 데이터 저장. 서버 위치: 싱가포르. Firebase 개인정보 안내
  • GitHub Pages(GitHub, Inc.) — 웹 게임 배포. 접속 시 IP 등 일반적인 웹 서버 접속 기록이 GitHub에 남을 수 있습니다.

7. 이용자의 권리

기록 열람·삭제를 원하시면 연락처로 요청해 주세요. 앱 안에서는 랭킹에 올린 본인 기록만 수정·삭제할 수 있도록 서버 규칙이 설정되어 있습니다.

8. 안전 조치

모든 통신은 HTTPS로 암호화됩니다. 서버 규칙으로 본인 기록 외에는 쓰기·수정·삭제를 막고 있으며, 랭킹 외의 데이터 영역에는 접근할 수 없습니다.
