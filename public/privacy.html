SEED 개인정보 처리방침

최종 수정일: 2026년 9월 24일 · 적용 대상: SEED 안드로이드 앱 및 웹 게임(kukuma1004.github.io/seed-web)

요약 — SEED는 계정 로그인을 강제하지 않습니다. 게스트로 플레이하거나 Google·Apple 계정을 선택해 로그인할 수 있습니다. 명예의 전당을 위해 플레이어가 직접 적은 별명, 사용자 ID와 게임 기록이 서버에 저장됩니다. 광고와 결제는 없습니다.

게스트 식별자는 Google·Apple 계정이나 실제 신원과 연결되지 않습니다. 앱을 지우면 게스트 진행을 되찾지 못할 수 있습니다. 계정 로그인을 선택한 경우 Firebase UID가 해당 로그인 제공자의 계정과 연결됩니다.

웹 이용 통계에는 이메일·별명·게임 조합·상세 오류 문구를 넣지 않습니다. 임의 식별자는 같은 브라우저의 하루 방문을 중복 계산하지 않기 위한 것으로, 브라우저 데이터를 지우면 새 식별자가 생길 수 있습니다. Android 앱은 이 웹 통계에 포함되지 않습니다.

2. 수집하지 않는 정보

법적 이름·생년월일·전화번호·주소·연락처·기기에 저장된 사진·마이크·카메라·정확한 위치·하드웨어 식별자(광고 ID 포함)를 요구하거나 수집하지 않습니다. 앱은 카메라, 마이크, 위치, 연락처, 저장소 권한을 요구하지 않습니다.

3. 광고와 결제

현재 버전에는 광고와 앱 내 결제가 없습니다. 추후 추가될 경우 이 문서를 먼저 고치고, 앱 안에서도 안내합니다.

4. 청소년 이용

SEED는 만 13세 이상 청소년과 성인을 대상으로 합니다. 별명에는 실명, 학교, 학년·반, 전화번호처럼 자신을 알아볼 수 있는 정보를 적지 않도록 게임 안에서 안내합니다. 부적절한 랭킹 별명은 앱 안에서 신고하거나 사용자 단위로 숨길 수 있습니다. 보호자께서 자녀의 기록 삭제를 원하시면 아래 연락처로 별명과 대략적인 기록 시각을 알려 주세요. 확인 후 삭제합니다.

5. 보관 기간과 파기

랭킹 기록과 계정 진행도는 서비스 제공을 위해 보관하며, 시즌 정리·계정 삭제·삭제 요청 시 지웁니다. 베타테스터 신청 정보는 테스트 종료 또는 신청 철회 시 지웁니다. 기기 안의 저장 내용은 앱 삭제 또는 브라우저 저장소 삭제로 사라집니다. Google·Apple 계정에 연결하지 않은 게스트는 앱을 지우면 같은 익명 UID에 다시 접근하지 못할 수 있습니다.

6. 제3자 제공과 처리 위탁

수집한 내용을 판매하거나 광고 목적으로 제공하지 않습니다. 다만 서비스 운영을 위해 아래 회사의 기능을 사용합니다.

  • Google Firebase(Google LLC) — 게스트·Google·Apple 계정 인증과 랭킹 데이터 저장. 랭킹 데이터 서버 위치: 싱가포르. Firebase 개인정보 안내
  • Apple(Apple Inc.) — 사용자가 Apple 로그인을 선택한 경우 계정 인증. Apple의 이메일 가리기 기능을 선택하면 임의 중계 주소가 제공될 수 있습니다.
  • GitHub Pages(GitHub, Inc.) — 웹 게임 배포. 접속 시 IP 등 일반적인 웹 서버 접속 기록이 GitHub에 남을 수 있습니다.

7. 이용자의 권리

기록 열람·삭제를 원하시면 연락처로 요청해 주세요. 앱 안에서는 랭킹에 올린 본인 기록만 수정·삭제할 수 있도록 서버 규칙이 설정되어 있습니다.

8. 안전 조치

모든 통신은 HTTPS로 암호화됩니다. 서버 규칙으로 계정 진행도는 해당 Firebase UID만 읽고 쓸 수 있으며, 운영 보상 지급서는 해당 UID만 읽을 수 있습니다. 다른 이용자의 진행도에는 접근할 수 없습니다.
