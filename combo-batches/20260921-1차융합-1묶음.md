## 시작 전 감사 (§12-1)

- 1차 융합 45칸 가운데 **공개 20개**가 손으로 만들어져 있다. 20개 모두 이름·한 줄 정체성·강점·약점·발동 조건이 코드에 들어 있고, 전용 탄환 지오메트리와 적중 연출을 가진다.
- **차원(portal) 법칙이 들어간 9칸은 법칙 자체가 숨겨져 있어(HIDDEN_LAWS) 이번 범위 밖**이다.
- 남은 **16칸**이 실제 미완성분이다. 이 묶음은 그중 다섯을 만든다. 남은 11칸:
  천둥 거울(반사+연쇄) · 태양 거울(반사+폭발) · 메아리 회랑(반사+귀환) · 꿰뚫는 꽃비(관통+분열) ·
  끌림 꽃밭(중력+분열) · 서리 꽃잎(빙결+분열) · 창날 고리(공전+관통) · 밀물 고리(공전+귀환) ·
  강착 원반(중력+공전) · 서리 되감기(빙결+귀환) · 얼어붙은 블랙홀(빙결+중력)
- 같은 이름의 **쌍둥이 각성**(단독 진화 두 개)이 이미 있다. 이름을 나란히 두되 ID는 겹치지 않게 한다.
  예: 1차 융합 `icicle` 고드름 창 ↔ 쌍둥이 각성 `iciclespear` 고드름 창 각성.

## 조합별 설계

### icicle — 고드름 창 (관통 + 빙결) · 단일 대상

- 재료 법칙: 관통 · 빙결
- 한 줄 정체성: 창이 적을 얼리고, **자기가 얼린 적**을 다시 꿰뚫으면 얼음째 깨뜨린다.
- 주 전투 동사: 박는다 → 깨뜨린다
- 발동 조건: 같은 적을 표식이 남아 있는 3.5초 안에 두 번 맞히기
- 강점: 혼자 버티는 단단한 적(문지기·보스), 같은 자리를 계속 노릴 때
- 약점·카운터: 여럿에게 나눠 쏘면 표식이 남지 않아 파쇄가 거의 안 터진다. 관통 수가 4로 낮다.
- 단일 대상 목표: Lv.4 두 발 기준 피해 = 2×damage + shatter
- 다수전 목표: 줄 관통 4까지, 파쇄 없음
- 방패 상호작용: 관통이 들어가 방패병 정면을 그대로 뚫는다
- 보스 제어 제한: 서리는 기존 보스 감속 하한(0.8)을 그대로 따른다. 파쇄는 피해만 준다.
- 궤적: 즉발 직선(히트스캔)
- 카드 실루엣: 고드름 한 자루, 끝이 갈라진 결정
- 탄환 유전자: 중심핵 얼음 결정 / 외피 서리 / 탄두 뾰족한 고드름 / 꼬리 서리 자국 / 표식 파란 결정 고리
- 적중 반응 순서: 관통 → (표식 없으면) 서리 고리 · (표식 있으면) 얼음 폭발 → 주변 22% 여파
- 오버드라이브·궁극기 골격: BEAM (가까운 적 넷에게 고드름 창을 즉시 박음)
- 피날레 동작: 네 자루가 동시에 박히고 표식이 한꺼번에 깨진다
- 발사·적중·조건 성공 소리: 기존 `frostHit`(파쇄 성공 시에만)
- 화면 최대 탄환 수: 0 (히트스캔)
- 화면 최대 VFX 수: 창 자국 10 + 파쇄 1
- 저장·옛 저장 처리: 새 ID라 옛 저장에 없다. 기존 저장은 그대로 열린다.
- 도감 설명: 코드의 desc 그대로
- 아직 해결할 문제: 없음

### halobloom — 꽃잎 후광 (공전 + 분열) · 다수전

- 재료 법칙: 공전 · 분열
- 한 줄 정체성: 씨앗을 도는 꽃잎 고리가 적을 베고, **여덟 번 베면** 꽃잎이 모두 바깥으로 만개한다.
- 주 전투 동사: 모았다 흩뿌린다
- 발동 조건: 고리로 적을 8번 베기(붙은 적이 많을수록 빨리 찬다)
- 강점: 사방에서 붙는 무리
- 약점·카운터: 만개한 뒤 고리가 잠시 비어 무방비. 멀리서 쏘는 적에게는 아예 닿지 않는다.
- 단일 대상 목표: 고리 피해만(적별 0.38초 재타격)
- 다수전 목표: 붙은 적 수에 비례 + 만개 한 번
- 방패 상호작용: 고리와 꽃잎 모두 관통이 없어 방패 정면은 막힌다(측후면으로 돌아야 한다)
- 보스 제어 제한: 밀치기 없음, 순수 피해
- 궤적: 공전 고리 → 바깥으로 방사, 적중 시 두 갈래
- 카드 실루엣: 씨앗을 감싼 꽃잎 고리와 밖으로 터지는 꽃잎
- 탄환 유전자: 중심핵 꽃씨 / 외피 꽃잎 / 탄두 둥근 끝 / 꼬리 꽃가루 / 표식 없음
- 적중 반응 순서: 벤다(고리) → 만개 → 꽃잎 적중 → 두 갈래 분열
- 오버드라이브·궁극기 골격: ORBIT (즉시 만개)
- 피날레 동작: 고리가 한 번에 벌어졌다 다시 자란다
- 발사·적중·조건 성공 소리: `split`(만개 순간)
- 화면 최대 탄환 수: 만개 8장 + 분열 16장, 상한 40
- 화면 최대 VFX 수: 벨 때마다 작은 고리 1
- 저장·옛 저장 처리: 새 ID
- 도감 설명: 코드의 desc 그대로
- 아직 해결할 문제: 없음

### frostnet — 얼어붙은 그물 (연쇄 + 빙결) · 제어

- 재료 법칙: 연쇄 · 빙결
- 한 줄 정체성: 번개가 **세 적 이상**을 이으면 그 선 위에 서리 줄이 남아 지나는 적을 얼린다.
- 주 전투 동사: 묶는다
- 발동 조건: 한 번에 세 마리 이상 잇기
- 강점: 길목을 얼려 무리의 발을 묶는다
- 약점·카운터: 피해가 가장 낮다. 적이 둘 이하면 줄이 아예 안 남는다.
- 단일 대상 목표: damage 한 번뿐(가장 약함)
- 다수전 목표: 연쇄 피해 + 줄 위 지속 피해
- 방패 상호작용: 연쇄는 간접 타격이라 방패를 우회한다
- 보스 제어 제한: **문지기·오스틴·항상초심·포탑은 줄 위에서 느려지지 않는다**(피해만)
- 궤적: 적 사이를 잇는 번개 → 바닥에 남는 서리 선
- 카드 실루엣: 적을 잇는 번개 선과 그 위에 앉은 서리
- 탄환 유전자: 히트스캔 아크 / 표식 바닥 서리 선
- 적중 반응 순서: 연쇄 적중 → 세 번째부터 선이 남음 → 0.5초마다 선 위 빙결
- 오버드라이브·궁극기 골격: DOMAIN (가까운 적 셋에서 각각 그물을 시작)
- 피날레 동작: 세 그물이 겹쳐 방 한가운데가 얼음판이 된다
- 발사·적중·조건 성공 소리: 기존 연쇄 소리
- 화면 최대 탄환 수: 0
- 화면 최대 VFX 수: 선 6개 × 0.5초 간격 자국
- 저장·옛 저장 처리: 새 ID
- 도감 설명: 코드의 desc 그대로
- 아직 해결할 문제: 없음

### rewindbolt — 되감는 번개 (연쇄 + 귀환) · 이동 보상

- 재료 법칙: 연쇄 · 귀환
- 한 줄 정체성: 번개가 지나간 길을 기억했다가, **씨앗이 충분히 움직이면** 그 길을 되감아 한 번 더 흐른다.
- 주 전투 동사: 되감는다
- 발동 조건: 번개를 친 뒤 일정 거리(Lv.1 5 → Lv.9 3.8) 이동
- 강점: 움직이며 같은 무리를 두 번 훑는다
- 약점·카운터: 제자리에 서 있으면 기억한 길이 4초 뒤 그냥 사라진다. 한 마리만 맞히면 되감을 길이 없다.
- 단일 대상 목표: 되감기 없음(길이 두 점 미만)
- 다수전 목표: 연쇄 피해 + 되감기 70%
- 방패 상호작용: 연쇄와 되감기 모두 간접 타격
- 보스 제어 제한: 제어 효과 없음, 피해만
- 궤적: 연쇄 아크 → 같은 선을 되감는 두 번째 아크
- 카드 실루엣: 두 겹으로 겹친 번개 길
- 탄환 유전자: 히트스캔 아크 / 표식 기억한 길(최대 2개)
- 적중 반응 순서: 연쇄 → 이동 → 같은 길 재생
- 오버드라이브·궁극기 골격: TIME STOP (가까운 적 셋의 길을 즉시 되감음)
- 피날레 동작: 세 길이 동시에 되감긴다
- 발사·적중·조건 성공 소리: `chainHit`(되감기 순간)
- 화면 최대 탄환 수: 0
- 화면 최대 VFX 수: 기억 2개 × 아크 6
- 저장·옛 저장 처리: 새 ID
- 도감 설명: 코드의 desc 그대로
- 아직 해결할 문제: 없음

### refractlance — 굴절 창 (관통 + 반사) · 방어·엄폐 대응

- 재료 법칙: 관통 · 반사
- 한 줄 정체성: 창이 벽에 닿으면 **꺾여 한 번 더 뻗고**, 꺾인 창은 더 깊이 박힌다.
- 주 전투 동사: 꺾는다
- 발동 조건: 벽이나 엄폐물 쪽으로 쏘기
- 강점: 엄폐물·벽이 많은 방에서 한 발로 두 줄을 꿰뚫는다. 방패병 정면을 그대로 뚫는다.
- 약점·카운터: 트인 방에서는 꺾일 벽이 없어 평범한 창 한 자루다.
- 단일 대상 목표: damage × (1 + 0.22 × 꺾은 횟수)
- 다수전 목표: 관통 예산(Lv.4 6)을 꺾인 구간과 나눠 쓴다
- 방패 상호작용: 관통이라 방패 정면을 뚫는다
- 보스 제어 제한: 제어 효과 없음
- 궤적: 즉발 직선 → 벽에서 꺾임(최대 3회)
- 카드 실루엣: 벽에 부딪혀 꺾인 창
- 탄환 유전자: 히트스캔 / 꼬리 관통 자국(꺾인 뒤 강조) / 표식 꺾임 지점의 반사 섬광
- 적중 반응 순서: 관통 → 꺾임 섬광 → 다음 구간 관통(피해 +22%)
- 오버드라이브·궁극기 골격: BEAM (다섯 방향 부채꼴로 꺾이는 창)
- 피날레 동작: 다섯 자루가 벽을 따라 방을 접는다
- 발사·적중·조건 성공 소리: `reflect`(꺾임 순간)
- 화면 최대 탄환 수: 0
- 화면 최대 VFX 수: 구간마다 자국 9 + 꺾임 섬광 3
- 저장·옛 저장 처리: 새 ID
- 도감 설명: 코드의 desc 그대로
- 아직 해결할 문제: 없음
