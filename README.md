# SEED · 잠든 정원

씨앗이 법칙을 조합하며 자라는 작은 액션 로그라이크. PC와 모바일 브라우저에서 플레이합니다.

**[바로 플레이](https://kukuma1004.github.io/seed-web/) · [JP Math Lab 게임](https://kukuma1004.github.io/jpmath-lab/games/)**

## 조작

- PC: WASD 또는 방향키 이동(화면 기준 상하좌우), Space 회피, E 출구, P/Esc 일시정지.
- 모바일: 왼쪽 스틱 이동, 오른쪽 ◇ 회피. 가로 화면을 권장합니다.
- 공격은 항상 자동입니다. 엄폐물에 가리지 않은 가까운 적을 겨냥합니다. 멈춘 상태의 회피는 마지막 이동 방향을 따릅니다.
- 보상과 출구는 화면 버튼으로 선택할 수 있습니다.
- `전체화면` 버튼과 `홈 화면 설치` 안내를 제공합니다. 화면 방향 잠금과 설치 지원은 기기·브라우저마다 다릅니다. iPhone에서는 Safari 공유 메뉴의 ‘홈 화면에 추가’를 이용해 보세요.

## 현재 구현

하나의 기본 씨앗으로 시작해 네 방과 문지기를 통과하고, 법칙과 레벨을 유지한 채 다음 여정을 선택합니다. 반사·분열·연쇄·공전·관통·폭발·귀환·중력·빙결의 9종 법칙 중 최대 5종을 가집니다.

**법칙은 바꾸지 않고 쌓습니다.** 적을 처치하면 화면 위쪽의 게이지가 차고, 가득 차면 세 후보 중 하나를 고릅니다. 필요한 처치 수는 선택할수록 늘어납니다(12 → 20 → 28 …). 5칸이 찬 뒤에는 가진 법칙의 레벨만 올리며, 레벨에는 상한이 없습니다. 파편·꽃잎·연쇄 수는 화면이 넘치지 않도록 상한이 있고, 강화할 때마다 모든 탄 피해가 10%씩 계속 오릅니다. 중력+폭발, 공전+빙결, 귀환+관통을 모으면 완성 진화를 고를 수 있고, 발견한 진화는 쓰러져도 남습니다.

방을 마쳐도 생명력은 회복되지 않습니다. 문지기를 쓰러뜨린 뒤 고르는 다음 지역에서만 회복합니다. 기본 공격은 6발을 쏜 뒤 1.25초 재장전하며, 씨앗 위에 생명력·탄창·회피 게이지가 표시됩니다.

두 번째 방부터 **포탑**이 등장합니다. 포탑은 씨앗이 가장 높게 키운 법칙 두 개를 따라 합니다(분열이면 세 갈래, 반사면 튕기는 탄, 연쇄면 표시한 자리에 번개, 공전이면 주위를 도는 구슬 등). 바닥의 **가시 함정**은 붉게 빛난 뒤 솟아오르며 적도 다치게 합니다. 적 탄환은 어두운 핵에 붉은 테, 문지기 탄환은 가시 달린 자홍색 별로 씨앗의 탄과 구분됩니다.

문지기는 여정마다 바뀝니다. 기억의 문지기는 첫 두 법칙을 배우고, 봉인의 문지기는 보라색 원이 닫힐 때 안에 있으면 회피를 3.5초 봉인하며, 추격의 문지기는 연속으로 두 번 돌진합니다. 네 번째 방에는 다음 문지기의 약한 분신이 먼저 나타납니다. 방패병은 정면의 직접 탄환을 막지만 옆·뒤와 돌진 후 회복 중에는 취약합니다.

같은 기기·브라우저의 저장 공간에 **방 입구를 자동 저장**합니다. 법칙 레벨과 처치 게이지도 함께 저장합니다. 사망하면 현재 도전 기록은 삭제되고, 새 씨앗으로 시작하면 기존 도전을 교체합니다. 저장 공간 차단·삭제 또는 다른 기기에서는 이어할 수 없습니다.

반사의 푸른 튕김, 분열의 산호색 파편, 연쇄의 금빛 번개, 회피 잔상과 진화 파동으로 법칙을 구분합니다. 모바일에서는 이펙트 수를 줄이고 네 개의 고정 묶음으로 그립니다.

이번 버전은 규칙 검사 15종과, 실제 키 입력으로 선택 주기·회복 없음·포탑의 법칙 복사·봉인의 문지기 회피 봉인을 브라우저에서 확인했습니다. 사람이 느끼는 난이도는 직접 플레이로 확인이 필요합니다. 실물 휴대폰 성능과 오프라인 실행은 아직 검증하지 않았습니다. 계속 개발 중인 시험판입니다.

## 개발

Node.js 24 환경에서 `npm ci`, `npm run dev`로 실행합니다. `npm test`로 규칙을 검사하고 `npm run build`로 배포 파일을 만듭니다.

main 브랜치에 올리면 GitHub Actions가 검사·빌드 후 GitHub Pages에 반영합니다. 게임 파일은 dist에서 생성하며 직접 수정하지 않습니다.

## 자산

선택 카드와 법칙 아이콘은 기존 SEED 언리얼 프로젝트의 원본 법칙 일러스트를 사용합니다. 플레이어는 네 방향으로 그린 투명 배경 씨앗 일러스트를 사용하며, 문지기는 새 네 방향 일러스트, 방패병·추격자·사수는 기존 언리얼 원본 투명 이미지를 사용합니다. 지형과 법칙 부속물은 코드로 만든 3D 모델입니다. 돌의 색상·노멀 텍스처는 이 프로젝트를 위해 생성했습니다. 게임 화면은 생성 이미지를 배경으로 붙인 것이 아니라 실제 Three.js 렌더링입니다.
