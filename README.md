# SEED · 잠든 정원

씨앗이 법칙을 조합하며 자라는 작은 액션 로그라이크. PC와 모바일 브라우저에서 플레이합니다.

**[바로 플레이](https://kukuma1004.github.io/seed-web/) · [JP Math Lab 게임](https://kukuma1004.github.io/jpmath-lab/games/)**

## 조작

- PC: WASD 이동, Space 회피, E 출구, P/Esc 일시정지.
- 모바일: 왼쪽 스틱 이동, 오른쪽 ◇ 회피. 가로 화면을 권장합니다.
- 공격은 항상 자동입니다. 엄폐물에 가리지 않은 가까운 적을 겨냥합니다. 멈춘 상태의 회피는 마지막 이동 방향을 따릅니다.
- 보상과 출구는 화면 버튼으로 선택할 수 있습니다.
- `전체화면` 버튼과 `홈 화면 설치` 안내를 제공합니다. 화면 방향 잠금과 설치 지원은 기기·브라우저마다 다릅니다. iPhone에서는 Safari 공유 메뉴의 ‘홈 화면에 추가’를 이용해 보세요.

## 현재 구현

하나의 기본 씨앗으로 시작해 네 방과 문지기를 통과하고, 법칙을 유지한 채 다음 여정을 선택합니다. 다음 여정은 기존 방 구조를 반복하며 적의 체력과 행동 속도가 올라갑니다. 반사·분열·연쇄·공전·관통·폭발·귀환·중력·빙결의 9종 법칙 중 최대 5종을 조합합니다. 전투 중간과 방을 마쳤을 때 총 8번 선택하며, 매번 세 후보와 조합 힌트를 보여줍니다. 이미 가진 법칙은 변이로 강화할 수 있습니다. 5칸이 차면 다른 법칙으로 교체하는 선택도 등장해 이후 여정에서도 조합을 바꿀 수 있습니다.

첫 여정에는 일반 군집 90마리와 정예·방패병·문지기 16마리가 등장합니다. 방패병은 정면의 직접 탄환을 막지만 옆·뒤와 돌진 후 회복 중에는 취약합니다. 주변 적을 통한 연쇄·폭발과 공전도 공략 수단입니다. 문지기는 위치 이동, 3회 연속 부채꼴 사격, 돌진, 근거리 충격파를 사용하며 플레이어의 첫 두 법칙을 배웁니다.

같은 기기·브라우저의 저장 공간에 **방 입구를 자동 저장**합니다. 전투 중 종료하면 해당 방 입구부터, 방 보상을 마치면 다음 방부터 이어갑니다. 문지기 격파 후에는 다음 지역 선택을 저장합니다. 일시정지 메뉴에서 시작 화면으로 돌아갈 수 있습니다. 사망하면 현재 도전 기록은 삭제되고, 새 씨앗으로 시작하면 기존 도전을 교체합니다. 저장 공간 차단·삭제 또는 다른 기기에서는 이어할 수 없습니다. 기억 조각·영구 해금은 아직 구현하지 않았습니다.

반사의 푸른 튕김, 분열의 산호색 파편, 연쇄의 금빛 번개, 회피 잔상과 진화 파동으로 법칙을 구분합니다. 모바일에서는 이펙트 수를 줄이고 네 개의 고정 묶음으로 그립니다.

이전 버전은 PC와 모바일 터치 에뮬레이션으로 완주를 검사했습니다. 이번 버전은 자동 공격·방향 표시·두 손가락 입력·방패 판정·보스 패턴·저장 데이터 검사와 브라우저의 저장 후 이어하기를 확인했습니다. 실물 휴대폰 성능과 오프라인 실행은 아직 검증하지 않았습니다. 계속 개발 중인 시험판입니다.

## 개발

Node.js 24 환경에서 `npm ci`, `npm run dev`로 실행합니다. `npm test`로 규칙을 검사하고 `npm run build`로 배포 파일을 만듭니다.

main 브랜치에 올리면 GitHub Actions가 검사·빌드 후 GitHub Pages에 반영합니다. 게임 파일은 dist에서 생성하며 직접 수정하지 않습니다.

## 자산

선택 카드와 법칙 아이콘은 기존 SEED 언리얼 프로젝트의 원본 법칙 일러스트를 사용합니다. 플레이어는 네 방향으로 그린 투명 배경 씨앗 일러스트를 사용하며, 문지기는 새 네 방향 일러스트, 방패병·추격자·사수는 기존 언리얼 원본 투명 이미지를 사용합니다. 지형과 법칙 부속물은 코드로 만든 3D 모델입니다. 돌의 색상·노멀 텍스처는 이 프로젝트를 위해 생성했습니다. 게임 화면은 생성 이미지를 배경으로 붙인 것이 아니라 실제 Three.js 렌더링입니다.
