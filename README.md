# SEED · 잠든 정원

씨앗이 법칙을 조합하며 자라는 작은 액션 로그라이크. PC와 모바일 브라우저에서 플레이합니다.

**[바로 플레이](https://kukuma1004.github.io/seed-web/) · [JP Math Lab 게임](https://kukuma1004.github.io/jpmath-lab/games/)**

## 조작

- PC: WASD 이동, 마우스를 누르면 수동 조준·발사, Space 회피, E 출구, P/Esc 일시정지.
- 모바일: 왼쪽 스틱 이동, 오른쪽 스틱 수동 조준·발사, ◇ 회피. 가로 화면을 권장합니다.
- 자동 공격이 기본입니다. 엄폐물에 가리지 않은 가까운 적을 겨냥하며 화면에서 켜고 끌 수 있습니다.
- 보상과 출구는 화면 버튼으로 선택할 수 있습니다.
- `전체화면` 버튼과 `홈 화면 설치` 안내를 제공합니다. 화면 방향 잠금과 설치 지원은 기기·브라우저마다 다릅니다. iPhone에서는 Safari 공유 메뉴의 ‘홈 화면에 추가’를 이용해 보세요.

## 현재 구현

하나의 기본 씨앗으로 시작해 네 방과 마지막 문지기를 통과합니다. 반사·분열·연쇄·공전·관통·폭발·귀환·중력·빙결의 9종 법칙 중 최대 5종을 조합합니다. 전투 중간과 방을 마쳤을 때 총 8번 선택하며, 매번 세 후보와 조합 힌트를 보여줍니다. 이미 가진 법칙은 변이로 강화할 수 있습니다.

일반 군집 90마리와 정예·문지기 14마리가 등장하고 동시 적 수는 최대 14마리입니다. 문지기는 플레이어의 법칙을 배워 공격을 바꿉니다. 사망·재시작을 지원하며 기억 조각·영구 해금은 아직 구현하지 않았습니다.

반사의 푸른 튕김, 분열의 산호색 파편, 연쇄의 금빛 번개, 회피 잔상과 진화 파동으로 법칙을 구분합니다. 모바일에서는 이펙트 수를 줄이고 네 개의 고정 묶음으로 그립니다.

PC 입력과 Chrome 모바일 터치 에뮬레이션으로 한 판 완주·선택·회피·재시작을 검사했습니다. 실물 휴대폰 성능과 오프라인 실행은 아직 검증하지 않았습니다. 계속 개발 중인 시험판입니다.

## 개발

Node.js 24 환경에서 `npm ci`, `npm run dev`로 실행합니다. `npm test`로 규칙을 검사하고 `npm run build`로 배포 파일을 만듭니다.

main 브랜치에 올리면 GitHub Actions가 검사·빌드 후 GitHub Pages에 반영합니다. 게임 파일은 dist에서 생성하며 직접 수정하지 않습니다.

## 자산

선택 카드와 법칙 아이콘은 기존 SEED 언리얼 프로젝트의 원본 법칙 일러스트를 사용합니다. 캐릭터와 지형은 코드로 만든 3D 모델입니다. 돌의 색상·노멀 텍스처는 이 프로젝트를 위해 생성했습니다. 게임 화면은 생성 이미지를 배경으로 붙인 것이 아니라 실제 Three.js 렌더링입니다.
